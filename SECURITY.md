# Security Policy

LabDraft's production source and infrastructure are private. This repository contains public product documentation only.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities through a public issue, discussion, or pull request.

Send a concise report to **kaizunlabs.ofc@gmail.com** with:

- The affected product area
- Reproduction steps that do not access another person's data
- Expected and observed behavior
- Any supporting screenshots with secrets and personal data removed

Do not include passwords, API keys, session tokens, private user content, or data belonging to other users.

## Scope

Security reports should concern the live LabDraft product at [labdraft.in](https://labdraft.in). The documentation in this repository is informational and does not expose the production implementation.
